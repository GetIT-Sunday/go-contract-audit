\section{Registered family and forward semantics}

The family contains the empty set, each of the following 11 singleton edits,
and eight specified pairs. Candidate membership is not a search over the entire
power set. Fixed semantics come from the frozen forward implementations, not
from fitting the observed metric discrepancy.

\section{Observation and matching}

The six controlled thresholds are 0.01, 0.10, 0.25, 0.50, 0.75 and 0.99. Pairwise
evidence contains prediction pairs at each threshold, truth pairs, per-protein
counts, aggregate metrics and the declared header. Counts-only evidence omits
the pair channels. Aggregate-only evidence additionally omits per-protein counts.
The Fmax-only ablation retains only the maximum protein-centric F1 across those
same thresholds, without the optimizing threshold.

Public JSON values are compared with frozen typed semantics. Mapping key order
is immaterial; sequences preserve order; booleans, integers and floats differ;
floats preserve exact binary representation and signed zero. Sets are represented
as canonically ordered sequences at the public boundary. These exact-match rules
are separate from external evaluator agreement at an absolute tolerance of 1e-12.

\begin{small}\begin{verbatim}
input: observed channels O, allowed projection L, registered candidates A
for each candidate a in A:
    replay its fixed field choices and project to L
E = all candidates whose projected channels equal O
M = all a in E for which no b in E is a strict subset of a
partition A by equality of projected channels
if E is empty: return unresolved
if M consists of the empty set: return observationally equivalent
if M has multiple members: return all minimal explanations
if L is aggregate-only: retain M but refuse specific attribution
otherwise: return the unique nonempty registered explanation
\end{verbatim}\end{small}

One minimal explanation may contain multiple axes. The result is relative to
the registered family; it cannot rule out unregistered causes with identical
observations. Private intervention histories can support controlled masking and
no-effect annotations, but are not inferred from this public procedure.

\section{Independent verification and comparison}

The independent matcher uses typed structural trees and a cardinality-ordered
antichain. It does not import production enumeration, minimality or signature
functions. All 336 retained cases were checked against both new production
outputs and sealed historical public outputs. Forward execution was checked
separately; its two implementations share projection and metric code.

Twelve hand-specified boundaries test empty explanations, unique singleton and
multi-axis explanations, incomparable alternatives, removal of matching strict
supersets, unmatched observations, observational equivalence, pair-to-count and
count-to-aggregate information loss, equal Fmax with different curves, evidence
specificity, and candidate-order/duplicate-ID handling. Seven representation
checks and the original hand-specified extension expectations were also retained.

The comparison seals outputs before scoring. Single-axis diagnosis uses 12
candidates and full diagnosis uses 20, under the same public evidence and refusal
policy. Fmax-only uses 20 candidates with explicitly reduced evidence. Preservation
is exact agreement of the minimal explanation sets with the independent reference
under the original observation scope; it does not call an information-reduced
matcher incorrect merely because information was removed.

Public unique-diagnosis denominators are 164 in the primary suite and 30 in the
extension. They differ from the historical intervention-category denominators
96 and 24. Historical coverage statuses are not revised. Zero action denominators
in the extension remain not estimable. Aggregate-only refusal is policy-imposed,
so its zero unique-diagnosis coverage is not a separate information-loss finding.

The primary suite has 24 pairwise, six counts-only and six aggregate-only cases
whose explanation sets require registered multi-axis candidates. Thirty of these
permit unique diagnosis under the public evidence rule. The extension shows no
advantage over single-axis diagnosis. Observational variants are dependent and
are not analyzed as independent samples for statistical significance.

\section{Actions, real cases and reproduction}

The new action assessment checks field restrictions and target values against an
independent rule implementation. It does not execute arbitrary emitted patches.
Controlled restoration uses precomputed counterfactual surfaces; retained real
restoration evidence comes from two specific replay workflows. The three real
walkthroughs were reconciled from retained summaries, without a new real replay.

The small capsule demonstrates the matcher on three precomputed public cases
(unique, equivalent and unresolved) with the full registry. It was reproduced
by a separate execution agent in a fresh Python 3.9.6 environment without pip
or third-party packages. Forward ontology computation, adapters and model
inference are outside this capsule's scope.

\section{Reproduction scope}
The local reproduction materials include the registered family, three precomputed public examples, the production matcher, an independently implemented reference, frozen expectations, and input hashes. The audit entry point does not read the expectations; a separate check compares the saved output with those expectations and the reference. Forward surface generation is outside the small component capsule. The accompanying artifact index maps these materials to the main results and states which workflows were replayed and which were reconciled from retained records.
