# Manuscript sources

The manuscript is `main.tex`; the bibliography is `references.bib`; the five
vector figures are under `figures/`; and the supplementary methods are under
`supplement/`.

Compile from this directory with a LaTeX toolchain that supports `natbib` and
the packages declared in `main.tex`. The source includes the full text and
uses the local figure PDFs. The supplementary methods are a separate document.

The manuscript describes bounded contract diagnosis and remediation checks.
It does not claim universal evaluator correctness, universal Fmax improvement,
or independent-team replication. The public repository intentionally omits
the original large model artifacts and restricted annotations.
